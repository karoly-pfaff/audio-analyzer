import { analyzeSignal, SignalAnalysisError } from '@karoly-pfaff/audio-analyzer/signal';
import type { SignalAnalysisSummary } from '@karoly-pfaff/audio-analyzer/signal';

export function trySignal(input: unknown):
  { status: 'complete'; summary: SignalAnalysisSummary } | { status: 'invalid'; code: SignalAnalysisError['code'] } {
  try {
    return { status: 'complete', summary: analyzeSignal(input) };
  } catch (error) {
    if (error instanceof SignalAnalysisError) return { status: 'invalid', code: error.code };
    throw error;
  }
}

Validate settings without running analysis

import { signalSettingsSchema } from '@karoly-pfaff/audio-analyzer/signal';
import type { SignalSettings } from '@karoly-pfaff/audio-analyzer/signal';

export function readSignalSettings(input: unknown): SignalSettings | null {
  const result = signalSettingsSchema.safeParse(input);
  return result.success ? result.data : null;
}

Every exported *Schema provides parse and safeParse. parse returns a validated value or throws; safeParse returns a discriminated success/data or error result. Neither fills in omitted settings fields. The direct signal/spectrum/tempo analysis calls translate invalid settings to their documented error classes; calling the schema directly returns Zod validation information.

Common questions

Why do original levels and musical energy differ?

Original signal metrics retain amplitude. Musical input can be attenuated, and its control channels are normalized per recording. Compare raw amplitude with original signal metrics, and use normalized channels for relative musical variation.

Why can stereo cancel in spectrum or tempo analysis?

The 'mean' policy averages channels. Opposite-phase samples can cancel. Select an existing channel index to analyze that channel independently.

Why are beats or beat phase absent?

Accepted musical rhythm requires observed events and supported intervals. A quick BPM estimate does not supply those events. Keep null phases and unavailable results visible in your application.

Does maximumFrames limit spectrum processing time?

It limits stored time columns. All source windows still contribute, so long input should run in a worker.

Why did passing SignalPcm back into analyzeSignal fail?

parseSignalPcm returns derived frameCount and durationSeconds. Analysis input is a strict two-field object: channels and sampleRate. Pass the original payload or construct that two-field object.

Can a cancellation signal stop a running synchronous estimate?

It is checked before work and before delivery. A blocked thread cannot process an asynchronous abort while the calculation runs; terminate the worker for active interruption.
