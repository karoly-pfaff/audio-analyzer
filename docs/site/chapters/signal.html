SIGNAL

Signal measurements and envelopes

analyzeSignal(input, settings?) measures original channel samples, including amplitudes above one and opposite-phase stereo. Calls read the input synchronously without normalizing, resampling or mutating it.

Original PCM input
Field Accepted values
channels 1–32 equally sized, nonempty Float32Array channels with finite samples.
sampleRate Integer 1–768,000 Hz, describing the actual PCM clock.
Sample budget At most 100,000,000 values across all channels. Duration follows this sample-value budget.
Duration Frames per channel divided by sample rate; never total interleaved values divided by sample rate.

The raw input contains only channels and sampleRate. parseSignalPcm(input) validates it and returns a SignalPcm with derived frameCount and durationSeconds, borrowing the channel storage. To analyze again, pass the original two-field payload: the parsed result has extra keys that strict input validation rejects.

Measurement fields

Field Meaning
peakAmplitude / peakDb Largest absolute sample and its dB value relative to amplitude one.
rmsAmplitude / rmsDb Root mean square over all channel sample values, and 20 log10(RMS).
dcOffset Signed arithmetic mean over all channel sample values.
crestFactorDb 20 log10(peak/RMS). Zero-amplitude input has null crest factor.
clippedSampleCount / clippedSampleRatio Count and fraction of channel samples whose absolute amplitude is at least clippingThreshold.
silentSampleRatio Fraction of channel samples whose absolute amplitude is below silenceThreshold.
channelMetrics The same measurements for each input channel, in input channel order.
frameCount / channelCount / durationSeconds Samples per channel, number of channels and frameCount/sampleRate.
settings / analyzerVersion / schemaVersion The settings and result identities to retain when saving measurements.

Zero peak/RMS produces null dB values. Positive amplitudes below one produce negative dB; amplitudes above one can produce positive dB. Pooled DC can cancel across channels, so inspect channelMetrics when channel-specific offsets matter. Sample peak and clipping thresholds do not measure inter-sample true peak or integrated loudness.

Clipping labels

clippingRisk is determined by clippedSampleRatio, using the same thresholds for aggregate and per-channel measurements:

Label Ratio r
none r = 0
low 0 < r < 0.00001
medium 0.00001 ≤ r < 0.0001
high r ≥ 0.0001

These are threshold labels, not probabilities. A clipped sample count is not the number of clipped time regions.

Settings and regions

Default signal settings; pass a complete settings object
Setting Default Range
clippingThreshold 0.999 (0, 1]
silenceThreshold 0.0001 (0, 1]
silenceWindowSeconds 0.05 (0, 10]
clippingWindowSeconds 0.01 (0, 10]
dynamicWindowSeconds 0.1 (0, 10]
minimumDynamicRms 0.000001 (0, 1]
maximumRegions 200 Integer 1–10,000

Silence requires all samples in every channel of a window to remain below threshold. A clipping window requires any channel sample to reach its threshold. Adjacent matching windows form a region. Endpoints are [startSeconds, endSeconds) source seconds, including the last partial window; they describe window boundaries rather than exact threshold-crossing sample times.

silence and clipping each contain regions, regionCount, longestRegionSeconds and regionsTruncated. The count and longest duration describe the complete input even when maximumRegions limits the stored list. Do not present a truncated list as the complete set of regions.

dynamicRangeProxyDb compares maximum/minimum RMS above minimumDynamicRms in complete dynamicWindowSeconds windows. It ignores the partial tail and needs enough input for two complete windows. If no window qualifies, or a window rounds down to zero samples, the result is null; one qualifying window produces zero dB. This proxy is not LUFS or standardized loudness range.

Waveform and RMS envelopes

createSignalEnvelope(input, columns?) accepts 1–65,536 columns, default 1,024. Its minimum, maximum, rms and transientActivity Float32Arrays all have exactly that length. Minimum/maximum include zero and all channels, so opposite-phase stereo retains its extrema. Original amplitudes above one remain above one.

Column i covers samples from floor(i * frameCount / columns) to ceil((i + 1) * frameCount / columns), bounded by the input. Rounded windows can overlap; very short input can repeat samples across columns. The final sample is included. Map samples to source seconds with sampleRate rather than treating a column as a new audio frame.

transientActivity is the positive difference between adjacent RMS buckets, scaled by the largest positive difference. It ranges from zero to one. The first value is zero; if there are no positive differences, all values are zero. It is a display descriptor and is not a musical onset timestamp.
