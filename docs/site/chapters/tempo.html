TEMPO

Tempo estimation and comparison

estimateQuickTempo(input, settings?, cancellation?) estimates BPM from the beginning of original PCM. Use the signal input contract. The result is an estimate for that prefix; it does not provide beat positions or a tempo map for the entire recording.

Settings and analyzed duration

Setting Default Accepted values
channel 'mean' 'mean' or integer 0–31 selecting a channel present in the input
maximumSeconds 60 Positive, at most 60 seconds

The analyzed prefix is at most maximumSeconds and 3,000,000 mono sample values, with at least one input frame selected. For example, at 96 kHz the sample limit caps analysis at 31.25 seconds even with maximumSeconds = 60. Samples are not resampled.

For every non-cancelled result, read analyzedFrameCount, analyzedSeconds and truncated alongside sourceFrameCount and sourceDurationSeconds. The result also includes sampleRate, hopSize, timeStepSeconds, fftSize, settings, analyzerVersion and schemaVersion. Audio shorter than the 2,048-sample FFT returns unavailable with insufficient-audio; a zero-valued selected signal returns silence.

Result states

Result states are a discriminated union
status Read these fields Interpretation
estimated bpm, confidenceLabel, confidenceBasis and metadata Display a provisional estimate; retain the heuristic basis.
unavailable reason: insufficient-audio, silence or insufficient-rhythm No BPM is available for this prefix.
failed code: estimator-failed or invalid-estimate Report a failure independently of unavailable rhythm.
cancelled schemaVersion and analyzerVersion only Discard the operation. Analysis metadata is not present. 
import type { QuickTempoResult } from '@karoly-pfaff/audio-analyzer/tempo';

export function describeTempo(result: QuickTempoResult): string {
  switch (result.status) {
    case 'estimated': return `${result.bpm} BPM (${result.confidenceBasis})`;
    case 'unavailable': return `No estimate: ${result.reason}`;
    case 'failed': return `Analysis failed: ${result.code}`;
    case 'cancelled': return 'Cancelled';
  }
}

Estimated BPM is rounded to one decimal. confidenceBasis is 'bpm-range-heuristic': high for an unrounded estimate of 60–160 BPM, medium for 40–220 outside that range, and low otherwise. A rounded BPM near a label boundary may appear to belong to the next range. These labels are not probabilities or observed-beat confidence scores.

insufficient-rhythm means the selected prefix did not provide a usable rhythmic estimate. A failed result uses estimator-failed when estimation could not complete, or invalid-estimate when it produced a nonfinite or out-of-range BPM (outside 1–1,000 before rounding). An unavailable result describes missing evidence; a failed result describes an unsuccessful calculation.

Cancellation

The third argument accepts { readonly aborted: boolean }; an AbortSignal fits this contract. A pre-aborted request returns cancelled before validating PCM or settings. A cancelled result has only status, schemaVersion and analyzerVersion. The flag is checked again before delivery, but cannot interrupt an already blocked synchronous calculation; terminate the application's worker for active interruption. 

import { estimateQuickTempo } from '@karoly-pfaff/audio-analyzer/tempo';

const controller = new AbortController();
controller.abort();
export const result = estimateQuickTempo(undefined, undefined, controller.signal);
// result.status === 'cancelled'; input validation is not reached.

Numeric BPM relationships

Function Result
normalizeBpm(bpm) Octave-folds positive BPM around the 60/120 boundary. Exact 120 normalizes to 60, while 59.9 normalizes to 119.8.
isHalfDoubleMatch(a, b) True when normalized tempos or their octave alternatives differ by at most 5 BPM. This also accepts equal/nearby tempos.
getBpmRelation(a, b) compatible for direct difference ≤ 2 BPM; close for ≤ 5; otherwise halfDouble for an octave match, or mismatch.
areBpmsCompatible(a, b) True for compatible, close and halfDouble; false only for mismatch. 
import { normalizeBpm, getBpmRelation, isHalfDoubleMatch, areBpmsCompatible } from '@karoly-pfaff/audio-analyzer/tempo';

export const comparisons = {
  folded: normalizeBpm(174),                 // 87
  nearby: getBpmRelation(120, 123),          // 'close'
  octave: getBpmRelation(60, 119.9),         // 'halfDouble'
  matches: isHalfDoubleMatch(60, 119.9),     // true
  compatible: areBpmsCompatible(120, 123), // true
};

These functions accept finite, positive numbers; strings, zero and nonfinite values throw TempoAnalysisError with invalid-bpm. Comparison helpers do not inspect audio or create beat positions.
