Preparing and retaining audio

Pass non-interleaved channel arrays with their actual sample rate. Signal measurements, spectrum and quick tempo accept the original channels. Musical analysis requires a separate mono 22,050 Hz copy. Keep the original samples if they are also used for playback or original-level measurements.

Copy PCM from a decoded browser buffer

The returned object can be passed directly to analyzeSignal, analyzeSpectrum or estimateQuickTempo. Copies are useful when transferring ownership to a worker; the analysis functions themselves read the supplied arrays without requiring a copy.

Decode a selected file in a browser

export async function decodeFile(file: File): Promise<ReturnType<typeof copyDecodedPcm>> {
  const context = new AudioContext();
  try {
    const decoded = await context.decodeAudioData(await file.arrayBuffer());
    return copyDecodedPcm(decoded);
  } finally {
    await context.close();
  }
}

This uses the browser's decoder. The returned sampleRate is the decoded clock, which can differ from the encoded file's rate. Keep it with the channel arrays rather than substituting a presumed file rate.

Prepare the musical copy

export async function prepareMono22050(decoded: AudioBuffer): Promise<Float32Array> {
  const context = new OfflineAudioContext(1, Math.max(1, Math.ceil(decoded.duration * 22050)), 22050);
  const source = context.createBufferSource();
  source.buffer = decoded;
  source.connect(context.destination);
  source.start();
  return (await context.startRendering()).getChannelData(0).slice();
}

This example renders into a mono 22,050 Hz browser buffer using Web Audio's channel mixing. For a required channel weighting or reproducible decoder policy, prepare PCM using that policy instead. Record the actual preparation in decoderVersion and compute pcmSha256 from your defined PCM byte representation before calling analyzeAudio.

Add this message listener to the same worker entry:

self.addEventListener('message', (event: MessageEvent<unknown>) => {
  self.postMessage(analyzeWorkerMessage(event.data));
});

In the calling application, send owned channel copies:

export function startSignalWorker(decoded: AudioBuffer): Worker {
  const input = copyDecodedPcm(decoded);
  const worker = new Worker(new URL('./analysis-worker.ts', import.meta.url), { type: 'module' });
  worker.postMessage(input, input.channels.map(channel => channel.buffer));
  return worker;
}

Attach message, error and messageerror listeners in the caller. A complete reply contains summary; a failed reply contains code. For concurrent requests, add a request ID so the caller can reject stale responses. Transferring detaches the copied arrays in the sender; retain the original playback buffer. Call worker.terminate() to interrupt active analysis, then create another worker for later work.

Save and restore results

Musical timelines use ordinary arrays and can be serialized as JSON. Validate restored content before use: 

import { audioFeatureTimelineSchema } from '@karoly-pfaff/audio-analyzer';
import type { AudioFeatureTimeline } from '@karoly-pfaff/audio-analyzer';

export function restoreTimeline(serialized: string): AudioFeatureTimeline {
  return audioFeatureTimelineSchema.parse(JSON.parse(serialized));
}

Spectrum frames and signal envelopes contain Float32Arrays. Choose an explicit array or binary representation; plain JSON.stringify does not preserve typed arrays. For example: 

import type { SpectrumResult } from '@karoly-pfaff/audio-analyzer/spectrum';

export function serializeSpectrum(result: SpectrumResult): string {
  return JSON.stringify({ ...result, frames: result.frames.map(frame => Array.from(frame)) });
}

When restoring spectrum or envelope data, validate the stored metadata and array dimensions in your application, then reconstruct Float32Arrays. There is no exported result schema for those outputs. Worker structured cloning preserves typed arrays without JSON conversion.

For cached analysis, retain source/PCM identity, preparation version, analyzerVersion and settings. Parsing a saved timeline validates its schema and relationships; it does not recompute its observations or upgrade an older algorithm result.
