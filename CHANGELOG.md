# Changelog

## 0.1.0

Initial version of @karoly-pfaff/audio-analyzer, licensed under MIT.

- Musical features, observed beats, sections and source-time timelines from prepared mono PCM.
- Original-channel signal measurements, clipping/silence regions and display envelopes.
- Display spectra with frequency/time metadata and full-spectrum centroid.
- Quick tempo result states and numeric BPM relationship functions.
- ESM entry points, TypeScript declarations and API usage examples.
